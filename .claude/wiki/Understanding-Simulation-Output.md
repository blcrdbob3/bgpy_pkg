This page explains the output files generated by BGPy simulations, their formats, and how to interpret them. After running a simulation, BGPy produces multiple output formats including CSV files for statistical analysis, pickle files for programmatic access, YAML files for debugging, and PNG graphs for visualization. For information about configuring what data is collected during simulation execution, see [Simulation Class and Execution Pipeline](/blcrdbob3/bgpy_pkg/4.1-simulation-class-and-execution-pipeline). For details on the analysis that produces these outputs, see [Outcome Analysis](/blcrdbob3/bgpy_pkg/8.1-outcome-analysis) and [Data Aggregation](/blcrdbob3/bgpy_pkg/8.2-data-aggregation).

### Pickle Output Format

The `graph_data.pickle` file contains Python objects for programmatic analysis. It stores a dictionary mapping `GraphCategory` objects to dictionaries of aggregated data.

**Pickle Data Structure:**

```
PICKLE_DATA_TYPE = dict[GraphCategory, dict[DataPointKey, DataPointAggData]]
```

The structure is:

- **Outer key**: `GraphCategory` - identifies the type of graph (plane, AS group, outcome, adoption filter)
- **Inner key**: `DataPointKey` - identifies a specific point (propagation round, percent adoption, scenario config)
- **Value**: `DataPointAggData` - contains `value` (mean), `yerr` (confidence interval), and `data_point_key`

This format is used by `GraphFactory` to generate visualizations without re-parsing CSV files.

### YAML Output Format

YAML files are generated per trial for debugging purposes. They contain the complete engine state and per-AS outcomes. The filename format is `{ScenarioCls}_{trial}.yaml`.

**YAML Contents:**

- Complete `BaseSimulationEngine` state (serialized via `SimulatorCodec`)
- Per-AS control plane outcomes (announcement origins)
- Per-AS data plane outcomes (actual traffic destinations)
- Propagation round information
- ROA validation results

These files enable detailed debugging of individual trials but are not used in the standard aggregation pipeline.

### Trial-Level Data Collection

For each trial, the `GraphDataAggregator.aggregate_and_store_trial_data()` method:

1. Creates `TrialData` objects for each `GraphCategory`
2. Iterates through all ASes in the graph
3. For each AS, checks if it matches the category filters (AS group, adoption status)
4. If matched, increments denominator and checks outcome
5. If outcome matches, increments numerator
6. Computes `percent = 100 * numerator / denominator` for that trial

Sources: [bgpy/simulation_framework/graph_data_aggregator/graph_data_aggregator.py75-117](https://github.com/blcrdbob3/bgpy_pkg/blob/39199d7d/bgpy/simulation_framework/graph_data_aggregator/graph_data_aggregator.py#L75-L117)[bgpy/simulation_framework/graph_data_aggregator/trial_data.py9-102](https://github.com/blcrdbob3/bgpy_pkg/blob/39199d7d/bgpy/simulation_framework/graph_data_aggregator/trial_data.py#L9-L102)

### Multi-Trial Statistical Aggregation

After all trials complete, `GraphDataAggregator` computes statistics:

- **Mean**: `value = mean(percent_list)` where `percent_list` contains all trial percentages
- **Error bars**: `yerr = 1.645 * 2 * stdev(percent_list) / sqrt(len(percent_list))` (90% confidence interval)

The factor `1.645` corresponds to the 90% confidence level for a normal distribution.

Sources: [bgpy/simulation_framework/graph_data_aggregator/graph_data_aggregator.py259-267](https://github.com/blcrdbob3/bgpy_pkg/blob/39199d7d/bgpy/simulation_framework/graph_data_aggregator/graph_data_aggregator.py#L259-L267)

- **X-axis**: Percent adoption (0-100%)

- Compare Y values across all specified attack scenarios
- Select the maximum Y value

2. Plot the aggregated line connecting maximum values

### Error Bar Calculation

Error bars represent 90% confidence intervals calculated as:

```
yerr = 1.645 * 2 * stdev(percent_list) / sqrt(n)

```

Where:

- `1.645` is the Z-score for 90% confidence
- `stdev(percent_list)` is the standard deviation across trials
- `n` is the number of trials
- Factor of `2` creates symmetric error bars (±yerr)

If only one trial was run, `yerr = 0` and no error bars are displayed.

Sources: [bgpy/simulation_framework/graph_data_aggregator/graph_data_aggregator.py259-267](https://github.com/blcrdbob3/bgpy_pkg/blob/39199d7d/bgpy/simulation_framework/graph_data_aggregator/graph_data_aggregator.py#L259-L267)

### Legend Sorting

Legends are automatically sorted by mean Y value (descending), placing the highest-performing scenarios at the top. This makes it easier to identify dominant policies at a glance.

## Working with Output Data

### Loading Pickle Data Programmatically

```
import pickle
from pathlib import Path

# Load the pickle file
pickle_path = Path("output_dir/graph_data.pickle")
with pickle_path.open("rb") as f:
    graph_data = pickle.load(f)

# Structure: dict[GraphCategory, dict[DataPointKey, DataPointAggData]]
for graph_category, data_dict in graph_data.items():
    print(f"Graph: {graph_category.outcome.name} on {graph_category.plane.name}")
    for data_point_key, agg_data in data_dict.items():
        print(f"  {data_point_key.percent_adopt*100}% adoption: "
              f"{agg_data.value:.2f}% ± {agg_data.yerr:.2f}%")
```

### Analyzing CSV Data

```
import pandas as pd

# Load CSV
df = pd.read_csv("output_dir/graph_data.csv")

# Filter for specific scenario
rov_data = df[df['AdoptingPolicyCls'] == 'ROV']

# Analyze attacker success in data plane
attacker_success = rov_data[
    (rov_data['outcome'] == 'ATTACKER_SUCCESS') &
    (rov_data['outcome_type'] == 'DATA')
]

# Plot custom analysis
import matplotlib.pyplot as plt
plt.errorbar(
    attacker_success['percent_adopt'] * 100,
    attacker_success['value'],
    attacker_success['yerr'],
    marker='o'
)
```

### Regenerating Graphs with Custom Styling

The `GraphFactory` class can regenerate graphs from existing pickle files with customized styling:

```
from pathlib import Path
from frozendict import frozendict
from bgpy.simulation_framework.graphing import GraphFactory, LineInfo

factory = GraphFactory(
    pickle_path=Path("output_dir/graph_data.pickle"),
    graph_dir=Path("output_dir/custom_graphs"),
    line_info_dict=frozendict({
        "ROV": LineInfo(
            label="ROV (Custom)",
            marker="o",
            ls="-",
            color="blue"
        )
    }),
    x_limit=100,
    y_limit=100,
)
factory.generate_graphs()
```

### Understanding Special Percent Adoptions

The `percent_adopt` field may contain special values from `SpecialPercentAdoptions`:

- `ONLY_ONE`: Exactly one AS adopts (useful for testing minimum deployment)
- `ALL_BUT_ONE`: All ASes except one adopt (useful for testing near-complete deployment)

These are stored as negative float values internally but have semantic meaning in analysis.
